## Structured Prompts

**Unstructured Prompt:** Help me prepare for a Python interview.  
**Output:** Practice coding questions, data structures, and basic concepts.

**Structured Prompt:**  
Role: Technical interviewer  
Task: Give 3 Python interview questions for beginners  
Format: Question + 1-line expected answer  
**Output:**  
1. What is a list vs tuple? — Lists are mutable; tuples are immutable.  
2. What is a dictionary? — Stores data as key-value pairs.  
3. What is `len()`? — Returns the number of items in an object.

**What Changed:** Defined Role, Task, and Format so the output came out organized and concise.
